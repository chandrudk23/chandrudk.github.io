Rentify

Product Rental Application & Admin Dashboard

RENTIFY is a product rental application designed to make renting high-value items — such as cameras, laptops, bikes, furniture, and home appliances — accessible and seamless. The project encompasses a mobile application for renters and a comprehensive web-based admin panel for monitoring inventory, tracking active rentals, and handling platform analytics.

Project Overview

Traditional rental processes are often hampered by unclear pricing tiers, ambiguous rental period calculations, and complicated deposit structures. RENTIFY was conceived to simplify the rental journey for users looking to access high-quality equipment without full ownership costs.

The design scope covered both sides of the ecosystem:

  • Consumer Mobile Experience: Product browsing across categories, flexible duration selection (daily, weekly, monthly), transparent deposit calculations, and a streamlined checkout flow.
  • Admin Management Dashboard: Centralized interface for administrators to manage product listings, process order requests, view active rental statuses, and monitor monthly revenue metrics.

Core Features & Workflows

User Mobile Application

  • User authentication & onboarding
  • Category-based product browsing & search filters
  • Flexible rental plan selector (Daily / Weekly / Monthly)
  • Transparent pricing & security deposit breakdown
  • Simple 3-step checkout & order status tracking

Admin Management Panel

  • Overview dashboard with key metric widgets
  • Product inventory management & availability toggle
  • Active order tracking & rental period monitoring
  • Customer activity records & verification status
  • Revenue analytics & financial tracking overview

User App Interface Design

High-contrast layouts, structured typography, and clear CTA placements ensure that users can evaluate rental terms and complete orders with minimal friction.

Admin Management Interface

The admin panel prioritises data scannability. Data tables, status tags, and control panels allow administrators to process requests and update inventory efficiently.

Reflection & Takeaways

Designing Rentify highlighted the importance of balancing two distinct user mindsets within a single product ecosystem: renters seeking speed and pricing clarity, versus platform operators requiring control and risk mitigation.

  • Systemic Consistency: Maintaining shared UI component logic between mobile and web dashboard environments sped up screen production and created a cohesive brand experience.
  • Clarity Over Complexity: Breaking down multi-tiered rental pricing into simple, selectable period pills significantly improved user clarity during testing.
